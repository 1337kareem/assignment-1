# COLORS

A LAMP stack web app. Someone can log in, save a list of colors, and search the colors. Each user can ONLY see their own colors.

## Technologies

HTML, CSS, JS, Apache, Linux, MySQL, PHP

## Setup

1. Create a MySQL database named COP4331 with a users and colors table.
2. Add a user row.
3. Copy api/config.example.php to api/config.php and fill your database info
4. Put the contents of public/ in your web root, with the api/ folder in it.

## Running it

Open http://your-server-address/index.html to log in.
You get taken to color.html, where you add and search colors.

## Limitations

There is no registration page.
The passwords are plain text.
